# BOLT ACTION FANMADE — versión modular 0.21

Esta versión separa el código de la versión 0.21 en archivos para facilitar su mantenimiento.

- `index.html`: estructura y punto de entrada.
- `css/estilos.css`: estilos visuales.
- `js/datos.js`: reglas, escenarios y datos del juego.
- `js/app.js`: navegación y funcionamiento de la aplicación.

Para probarla, abre `index.html` en un navegador. Para publicarla en GitHub Pages, conserva esta estructura de carpetas y sube todos los archivos al repositorio.

**Importante:** esta carpeta no incluye una carpeta de imágenes porque la imagen de fondo de la versión 0.21 está referenciada desde su dirección web original.
